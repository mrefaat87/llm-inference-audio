Jenny: That's literally the idle instance problem. This is why we built autoscaling — to keep utilization high without sacrificing latency. Every idle instance is pure waste.

Jenny: Oh, that's like the difference between raw throughput and successful request rate. We used to track this in load balancers — you could be processing tons of requests, but if half of them are 503s, your effective throughput is garbage.

Jenny: Okay, but you mentioned something earlier that I want to come back to. You said input tokens are much cheaper than output tokens. Why?

Alex: This is one of the most important asymmetries in inference economics. Input processing — the prefill phase — is compute-bound. You take the entire input prompt and process all those tokens in parallel through the model. It's a big matrix multiplication, and GPUs are incredible at parallel matrix math. You might process thousands of input tokens in the same time it takes to generate one output token.

Jenny: And output generation?

Alex: Output — the decode phase — is memory-bandwidth-bound. You're generating one token at a time per sequence. Each token requires reading the entire model weights from GPU memory. The GPU's compute units are mostly sitting idle, waiting for data to arrive from memory. It's like having a sixteen-lane highway but only one car on it.

Jenny: So input is throughput-optimized — you're fully utilizing the GPU. Output is latency-bound — you're bottlenecked on memory bandwidth. That's why providers charge 3 to 5x more for output.

Alex: Exactly. And this asymmetry is why disaggregated inference — separating prefill and decode onto different GPU pools — makes economic sense. You can optimize each pool independently. Pack your prefill GPUs for maximum compute utilization, configure your decode GPUs for maximum memory bandwidth efficiency.

Jenny: That's literally the microservices argument. Separate your compute-heavy path from your I/O-heavy path so you can scale and optimize them independently.

Alex: And the cost savings from disaggregation are typically 20 to 40 percent, which is significant when you're running thousands of GPUs.

Jenny: Okay, now there's one more thing I want to dig into. You mentioned thinking tokens earlier. What's the cost story there?

Alex: This is the new frontier of cost economics, and it's kind of terrifying. Jenny: So the user sees 500 tokens but the GPU processed up to 50,000?

Alex: Right. And providers typically bill thinking tokens at output token rates, because they cost the same to generate — each one requires that same memory-bandwidth-bound decode step. Jenny: That's like... running a complex query optimizer that evaluates thousands of execution plans before picking one. The user sees a fast query, but the system did enormous work behind the scenes.
